# Nishant Jain — Cinematic AI / Edge / IoT Portfolio

A responsive, single-page engineering portfolio using the chosen black, deep-teal and electric-cyan visual theme. The portal-inspired hero is built from CSS geometry and layered gradients, with a lightweight animated canvas layer. No 3D asset downloads or build step are required.

## Run locally

Python 3 is sufficient:

```bash
python -m http.server 8080
```

Open `http://localhost:8080` from this folder. Alternatively, open `index.html` directly in a modern browser.

## Included sections and interactions

- Cinematic portal hero, responsive navigation and animated background
- Selected projects: EdgeDesk, Crowd Analytics, Poultry Health AI and on-device AI assistant
- Project case-study dialogs with architecture flow diagrams
- Interactive technology constellation linking skills to relevant projects
- About, technology stack, experience timeline, recognition and contact sections
- CV PDF, GitHub, LinkedIn, email copy action and accessible mobile navigation
- Reduced-motion support, keyboard focus styles, metadata and social preview artwork

## Deploy

This is a static site. Upload the contents of this folder to GitHub Pages, Netlify, Cloudflare Pages, or any static web host. See `DEPLOYMENT.md` for launch checks.

## Accuracy notes

- EdgeDesk is described as having a **patent application filed**, not a granted patent.
- Project visuals are illustrative CSS artwork, not represented as screenshots of deployed products.
- Project metrics are only mentioned with context; no invented live-demo or repository URLs are used.
- Contact is via email and social links; there is no backend contact form.
- The Three.js CDN is optional and used only for the technology visualization; the portal remains CSS-based and works without an imported 3D model.
